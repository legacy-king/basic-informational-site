# Basic Informational Site

A simple multi-page website built with Node.js using only built-in modules — no Express, no frameworks. Demonstrates server-side routing and file serving with the `http` and `fs` modules.

## Pages

- `/` — Home page
- `/about` — About page
- `/contact` — Contact page
- Any other route — 404 page

## Built With

- Node.js
- `http` module
- `fs` module

## Getting Started

```bash
node index.js
```

Then open `http://localhost:8080` in your browser.
